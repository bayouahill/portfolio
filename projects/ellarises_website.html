Project Overview

Ella Rises is a comprehensive web application developed as part of the INTEX-4-14 project. The application provides a platform for managing and displaying information about the Ella Rises organization, including participant management, administrative controls, and public-facing content. Built with modern web technologies, the application features secure authentication, database-driven content management, and responsive design.

Key Features

  • User authentication system with separate admin and user roles
  • Database-driven content management using PostgreSQL and Knex.js
  • Admin panel for managing participants and content
  • Public-facing pages for displaying organization information
  • Secure session management with Express sessions
  • CSRF protection using csurf middleware
  • File upload capabilities with Multer
  • Responsive design with EJS templating
  • Interactive data visualizations with Chart.js for real-time analytics

Interactive Data Visualizations

The application features dynamic, interactive graphs integrated throughout the dashboard pages to provide real-time insights into organizational metrics. These visualizations transform raw database data into actionable intelligence for administrators and stakeholders.

Implementation Approach

  • Chart.js Integration: Implemented Chart.js library for rendering interactive bar charts, area charts, and line graphs directly in the browser
  • Server-Side Data Processing: Used Express.js routes to query PostgreSQL database and aggregate data (milestone categories, donation trends, participant statistics)
  • RESTful API Endpoints: Created dedicated API routes that return JSON data formatted specifically for chart consumption, enabling efficient data fetching
  • Real-Time Updates: Charts dynamically update based on database queries, ensuring administrators always see current metrics
  • Responsive Design: Visualizations adapt to different screen sizes while maintaining readability and interactivity

Visualization Features

  • Milestones Dashboard: Horizontal bar chart displaying distribution of milestone categories (Post-Secondary Education, STEAM Jobs, Awards, etc.) with percentage breakdowns and color-coded segments
  • Donations Dashboard: Area chart showing donation trends over time with interactive tooltips displaying specific dates and amounts, enabling trend analysis from 2022-2027
  • Interactive Tooltips: Hover functionality reveals detailed data points (dates, amounts, categories) without cluttering the interface
  • Summary Statistics Cards: Key metrics (total milestones, monthly achievements, future milestones) calculated from database queries and displayed alongside visualizations
  • Color-Coded Categories: Consistent color palette across charts for intuitive data interpretation

Technical Implementation

The visualization system follows a clean separation of concerns: backend Express routes handle data aggregation using Knex.js queries, returning structured JSON responses. Frontend JavaScript processes this data and configures Chart.js instances with appropriate chart types, scales, and styling. The implementation ensures that charts remain performant even with large datasets by leveraging database-level aggregations and efficient query patterns.

Backend Data Processing
  • Created Express route handlers that query PostgreSQL using Knex.js to aggregate milestone and donation data
  • Implemented GROUP BY queries to categorize milestones by type and calculate percentages
  • Used date aggregation functions to group donations by month/year for time-series visualization
  • Formatted query results as JSON objects with labels and data arrays matching Chart.js expected format
  • Added error handling to gracefully manage empty datasets or database connection issues
Frontend Chart Rendering
  • Embedded Chart.js library via CDN in EJS templates for dashboard pages
  • Created JavaScript modules that fetch data from Express API endpoints using fetch() or XMLHttpRequest
  • Initialized Chart.js instances with canvas elements, configuring chart types (bar, line, area) based on data requirements
  • Implemented responsive chart sizing using Chart.js responsive options and container queries
  • Customized chart appearance with color schemes matching the Ella Rises brand palette
  • Added interactive tooltip configurations to display detailed information on hover
  • Implemented chart update methods to refresh visualizations when new data is added to the database
Data Flow Architecture

The data flows from PostgreSQL → Express.js route handler → JSON response → Frontend JavaScript → Chart.js configuration → Rendered visualization. This architecture allows for real-time data visualization without page refreshes, as charts can be updated by making new API calls when administrators add or modify records.

Technical Stack

  • Backend: Node.js with Express.js framework
  • Database: PostgreSQL with Knex.js query builder
  • Templating: EJS (Embedded JavaScript) with express-ejs-layouts
  • Security: Helmet.js, CSRF protection, secure session management
  • File Handling: Multer for file uploads
  • Deployment: AWS Elastic Beanstalk with custom platform hooks
  • Data Visualization: Chart.js for interactive charts and graphs

Development Highlights

  • Implemented database migrations and seed files for consistent data structure
  • Designed and developed RESTful API routes for data management
  • Created reusable EJS components and layouts for consistent UI
  • Configured AWS Elastic Beanstalk deployment with post-deploy hooks
  • Implemented role-based access control for admin and user accounts
  • Optimized database queries and relationships using Knex.js

Project Structure

The application follows a MVC-like architecture with organized routes, views, and database migrations. The project includes comprehensive data seeding, migration files for database schema management, and platform-specific deployment configurations for AWS Elastic Beanstalk.
